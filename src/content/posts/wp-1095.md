<p>Nextcloud默认并不会开启 <strong>视频和PDF</strong> 的缩略图，大量文件时难免造成不便。其实，只要简单几步就可以启用上述功能</p>



<p>D酱的部分配置信息</p>



<ul><li>centOS 7</li><li>Nextcloud 18</li><li>php 7.3</li></ul>





## 安装 ffmpeg 和 <strong>ghostscript</strong>





<pre class="wp-block-syntaxhighlighter-code">wget http://download1.rpmfusion.org/free/el/rpmfusion-free-release-7.noarch.rpm
rpm -ivh rpmfusion-free-release-7.noarch.rpm

yum install ffmpeg ffmpeg-devel
yum install ghostscript</pre>



<pre class="wp-block-syntaxhighlighter-code">#使用ffmpeg检查安装
ffmpeg -version</pre>





## 修改config.php





<p>修改 <code>/nextcloud安装目录/config/config.php</code> 。在最后一个括号前插入以下内容：</p>





### Nextcloud [18\17\16]





<pre class="wp-block-syntaxhighlighter-code">'enabledPreviewProviders' => array (  
    0 => 'OC\\Preview\\PNG',  
    1 => 'OC\\Preview\\JPEG',  
    2 => 'OC\\Preview\\GIF',  
    3 => 'OC\\Preview\\HEIC',  
    4 => 'OC\\Preview\\BMP',  
    5 => 'OC\\Preview\\XBitmap',  
    6 => 'OC\\Preview\\MP3',  
    7 => 'OC\\Preview\\TXT',  
    8 => 'OC\\Preview\\MarkDown',  
    9 => 'OC\\Preview\\Movie',  
    10 => 'OC\\Preview\\PDF'  
),  </pre>



<div class="wp-block-image"><figure class="aligncenter size-full is-resized"><a href="https://cdn.dalaoweb.top/wp-content/uploads/2020/02/image-10.png"><img src="https://cdn.dalaoweb.top/wp-content/uploads/2020/02/image-10.png" alt="" class="wp-image-1124" width="905" height="438" loading="lazy" decoding="async"></a><figcaption>Nextcloud 18</figcaption></figure></div>



<p class="has-text-color has-background has-text-align-center has-very-light-gray-color has-vivid-cyan-blue-background-color">使用Nextcloud升级器升级到16以上时，会自动更正为新的语法</p>





### Nextcloud 15及以下





<p>对于Nextcloud 15及以下，应该使用以下配置：</p>



<pre class="wp-block-syntaxhighlighter-code">'enabledPreviewProviders' => array(
        'OC\Preview\PNG',
        'OC\Preview\JPEG',
        'OC\Preview\GIF',
        'OC\Preview\HEIC',
        'OC\Preview\BMP',
        'OC\Preview\XBitmap',
        'OC\Preview\MP3',
        'OC\Preview\TXT',
        'OC\Preview\MarkDown',
        'OC\Preview\Movie',
        'OC\Preview\PDF'
	),</pre>





## 禁用PHP函数





<p>禁用php中的 <code>exec</code> 和 <code>system</code> 函数，网上很多教程漏掉了这一步，导致视频缩略图无效。</p>

<p>之后重启Nginx和PHP就完成了</p>
