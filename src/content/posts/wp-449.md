#### 但是！





<p>因为使用WordPress自带的备份工具媒体导入失败了…很多图片无法在媒体库中显示出来，指向的还是原来的VPS文件夹…（<em>现在原VPS已销毁，不用再试了</em>）</p>



<p>这该怎么办？</p>





## 目前采用的并不完善的方法





<p>以将文件从www.dalaoweb.top转移到blog.dalaoweb.top为例</p>



<pre class="wp-block-syntaxhighlighter-code">cd /home/wwwroot/blog.dalaoweb.top/wp-content tar cvf upload.tar upload mv upload.tar /home/wwwroot/www.dalaoweb.top/</pre>



<p>2、在新VPS中使用wget命令下载tar文件（不得不说VPS之间的速度还是很快的，毕竟是1G的带宽）</p>



<pre class="wp-block-syntaxhighlighter-code">cd /home/wwwroot/blog.dalaoweb.top/
sudo wget www.dalaoweb.top/upload.tar</pre>



<p>3、解压缩覆盖原有的upload文件夹</p>



<pre class="wp-block-syntaxhighlighter-code">tar xvf upload.tar</pre>



<p>4、进入phpMyAdmin，使用SQL命令将所有原网址字段改为现在的网址。</p>



<pre class="wp-block-syntaxhighlighter-code">UPDATE wp_options SET option_value = replace( option_value, 'www.dalaoweb.top', 'blog.dalaoweb.top' );

UPDATE wp_posts SET post_content = replace( post_content, 'www.dalaoweb.top', 'blog.dalaoweb.top' );</pre>



<p>5、这样文章中的图片就会调用现在VPS中的图片了</p>





### 缺点：





<p>1、媒体库中不会显示</p>



<p>2、特色图片需要手动保存重新上传才能使用。</p>



<p>我也曾经试过复制数据库中原wp-post表+覆盖+替换字段…但媒体库中虽然有了文件，但都无法正常显示…有哪个好心的告诉我应该怎么做啊。</p>
