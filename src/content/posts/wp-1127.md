<p>nextcloud的<strong>文件锁</strong>是为了是防止多<strong>个用户同时对一个文件进行操作</strong>造成错误而诞生的。默认情况下，nextcloud使用的是<strong>基于数据库</strong>的文件锁，效率低下而且容易在大批量操作时造成意外上锁。使用Redis可以解决这个问题。</p>





## 安装Redis





<p class="has-text-color has-background has-text-align-center has-very-light-gray-color has-vivid-cyan-blue-background-color">关于基于命令行的Redis的安装、部署这里不再赘述，请自行Google/百度</p>



<p>宝塔可以快速帮助和我们完成Redis的配置</p>

## 配置Nextcloud





<p>nextcloud根目录/config/config.php下添加如下内容</p>



<pre class="wp-block-syntaxhighlighter-code">  'memcache.local' => '\\OC\\Memcache\\Redis',
  'redis' => 
  array (
    'host' => 'localhost',
    'port' => 6379,
   ),
  'memcache.locking' => '\\OC\\Memcache\\Redis',  #Redis文件锁,不使用可删去此行</pre>



<p>之后重启 nginx 或者重载配置即可</p>
