## 2020/4/1更新





<p>截止3月24号，Google上已经没有本站AMP网页的索引了，相关Rewrite代码已从Nginx上删除</p>

<div class="wp-block-spacer"></div>



<blockquote class="wp-block-quote"><p>Accelerated Mobile Pages（简称AMP，意为“加速移动页面”）是Google带领开发的开源项目，目的是为提升移动设备对网站的访问速度。AMP也可指其派生的标准和库等项目成果。AMP在HTML等广泛使用的网络技术基础上进行改良</p><cite><a href="https://zh.wikipedia.org/wiki/Accelerated_Mobile_Pages">维基百科</a></cite></blockquote>



<p>AMP这家伙可谓“<strong>请神容易送神难</strong>”。在WordPress上，添加AMP只需要一个插件便能将原有的网页自动格式化为AMP。但在不损害SEO的前提下将它移除，却不是那么容易。</p>



<p>在查询的Google相关的资料后，D酱的情况属于“<a href="https://developers.google.com/search/docs/guides/remove-amp?hl=zh-cn#remove-only-amp">仅移除 AMP 网页，同时保留规范的非 AMP 网页</a>”，需要如下操作：</p>



<ol><li>从规范的非 AMP 网页的源代码中移除&nbsp;<code>rel="amphtml"</code>&nbsp;链接。</li><li>将您的服务器配置为针对已移除的 AMP 网页返回&nbsp;<code>HTTP 301 Moved Permanently</code>&nbsp;或&nbsp;<code>302 Found</code>&nbsp;响应。</li><li>配置从已移除的 AMP 网页到规范的非 AMP 网页的重定向。</li></ol>



<p>对于第一项，卸载插件时会帮我们自动完成，而后两项则需要我们手动修改Nginx的配置文件来完成</p>



<p class="has-text-color has-background has-very-light-gray-color has-vivid-red-background-color">注意：千万不要在Search Console里使用“删除”功能，这会导致原有的非AMP页面被一同删除</p>



<div class="wp-block-image"><figure class="aligncenter size-large"><a href="https://cdn.dalaoweb.top/wp-content/uploads/2020/02/image-5.png"><img src="https://cdn.dalaoweb.top/wp-content/uploads/2020/02/image-5-1024x583.png" alt="" class="wp-image-1102" loading="lazy" decoding="async"></a></figure></div>



<p>在Google的Search Concole中查看到amp网址主要有这几种类型（会有这么多类型的原因全怪我乱改格式...）：</p>



<ul><li>domain/?p=abc/?amp=1</li><li>domain/?p=efg&amp;amp=1</li><li>domain/?amp=1&amp;abc=x&amp;efg=y…</li></ul>



<p>在站点配置文件中添加如下内容</p>



<pre class="wp-block-code"><code>    if ($request_uri ~ "^(.*?)\??\&amp;?amp=1\&amp;?(.*)"){
            set $args1 $1;
            set $args2 $2;
            set $args "";
            rewrite ^ "${args1}?${args2}" permanent;
    
    }
    if ($request_uri ~ "^(.*)\?$"){
            set $args1 $1;
            set $args "";
            rewrite ^ "${args1}" permanent;
    }</code></pre>



<p>之后<strong>重启Nginx</strong>或者<strong>重载配置</strong></p>



<p class="has-text-color has-background has-very-light-gray-color has-vivid-cyan-blue-background-color">如果试验时301重定向没有生效，可以尝试清除浏览器缓存或者使用无痕浏览（隐身）功能</p>



<p>经过本人的验证，这个方法对于图中的所有uri删除"amp=1"都是可行的</p>



<p class="has-text-color has-background has-very-light-gray-color has-vivid-cyan-blue-background-color">PS：“朴素”型的固定链接可能会影响SEO分数，建议尽快换成“数字型”或其他使用路径而不是查询字符串来索引文章的方式，WordPress会自动对旧链接进行重定向，例如<a href="/tech/psv/740/">https://blog.dalaoweb.top/?p=740/?amp=1</a>,在删除?amp=1后，会自动跳转到新的链接，可以说非常方便了</p>
